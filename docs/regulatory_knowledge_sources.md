# Regulatory Knowledge Base — Verified Government Sources

> **تنبيه حوكمة / Governance notice**
> هذه الوثيقة تفهرس **مصادر** رسمية فقط. لا تُعتبر أي قيمة مستمدة منها رسمية داخل النظام
> إلا بعد توثيق البند الدقيق (clause) من الوثيقة الرسمية واعتمادها من مهندس مرخص عبر
> سير عمل مراجعة القواعد (`/v1/rule-candidates/*`). روابط المواقع تم التحقق منها بتاريخ 2026-07-24.
>
> This document indexes official **sources** only. No value derived from them is treated
> as official inside the system until the exact clause is documented from the official
> publication and validated by a licensed engineer through the rule-review workflow.

## 1. كود البناء السعودي — Saudi Building Code (sbc.gov.sa)

**الجهة:** اللجنة الوطنية لكود البناء السعودي
**الإلزامية:** ملزم بموجب «نظام تطبيق كود البناء السعودي» ولائحته التنفيذية، وفق مراحل تطبيق حسب تصنيف المباني. متطلبات **العزل الحراري** و**الحماية من الحريق** تسري على جميع أعمال البناء الجديدة فورًا.

| الكود | النطاق | أولوية النظام |
|---|---|---|
| SBC 201 (طبعة 2024 مدرجة على الموقع) | الاشتراطات العامة: معماري، صحة عامة، تهوية | P0 |
| SBC 301–306 | الإنشائي: الأحمال، التشييد، التربة والأساسات، الخرسانة، المباني، الفولاذ | P0/P2 |
| SBC 401 | الكهربائي | P1 |
| SBC 501 | الميكانيكي | P1 |
| SBC 601 | ترشيد الطاقة (أساس بند "كفاءة الطاقة" في قائمة الجاهزية) | P1 |
| SBC 701 | التمديدات الصحية | P1 |
| SBC 801 | الحماية من الحريق (مرتبط بالدفاع المدني) | P0 |
| SBC 901 | المباني القائمة | P2 |
| **SBC 1101 / 1102** | **كود المباني السكنية** (المصدر الأساسي لفحوصات الفلل) | P0 |

**طريقة الحصول على القيم:** وثائق الكود تُحمّل من sbc.gov.sa (جداول محتويات متاحة للعموم؛ النصوص الكاملة عبر قنوات النشر الرسمية). القيم تُنقل يدويًا إلى «مرشحات القواعد» مع رقم البند، ثم تُعتمد مهنيًا.

**ملاحظة تصحيحية:** كود المباني السكنية هو **SBC 1101/1102** — بعض المصادر غير الرسمية تخلط بينه وبين "SBC 1001" (غير موجود في القائمة الرسمية).

## 2. نظام تطبيق الكود ولائحته — Code Application Law (momah.gov.sa)

- نظام تطبيق كود البناء السعودي (PDF رسمي على momah.gov.sa) — أساس الإلزام القانوني.
- اللائحة التنفيذية للنظام (نسخة محدثة 2025-10 على momah.gov.sa، ومنشورة في جريدة أم القرى uqn.gov.sa) — تحدد مهام مراجعة المخططات، إصدار الرخص، التفتيش، والعقوبات.

**قيمة للنظام:** هذه الوثائق تحدد *متى* يكون الكود ملزمًا ولمن — مدخل أساسي لتقييم "جاهزية التصريح" حسب تصنيف المبنى.

## 3. منصة بلدي — Balady (balady.gov.sa)

- خدمة إصدار رخصة بناء + دليل المستخدم الرسمي (balady.gov.sa/ar/node/24825).
- الاستعلام عن الرخص: apps.balady.gov.sa/Eservices/Inquiries/inquiry.
- متطلبات موثقة: صك إلكتروني محدث، رفع مساحي معتمد، تصميم مطابق للكود، عقد إشراف مع مكتب هندسي مرخص، سداد إلكتروني. سريان الرخصة والقرار المساحي: 3 سنوات.
- **الاشتراطات العمرانية (ارتدادات/تغطية/أدوار) تختلف حسب البلدية والنطاق** — يجب سحبها لكل موقع مشروع، ولا يجوز تعميمها.

**قيمة للنظام:** الأساس المباشر لقائمة فحص «جاهزية الرخصة» في `/v1/permit/readiness`.

## 4. أمانة منطقة الرياض — Riyadh Amanah (alriyadh.gov.sa)

- الدليل الإرشادي لاشتراطات رخص البناء: **trc.alriyadh.gov.sa**.
- صفحة الاشتراطات والضوابط: alriyadh.gov.sa/ar/municipality/conditionregul.
- ضوابط المخططات العمرانية الجديدة: اكتمال البنية التحتية والمجال العام قبل بدء البناء.
- تطبيق «مدينتي» لطلبات نظام البناء.

**قيمة للنظام:** أول «ملف اشتراطات إقليمي» (Riyadh profile) — نموذج لملفات بلديات أخرى لاحقًا.

## 5. الهيئة الملكية لمدينة الرياض — RCRC (rcrc.gov.sa)

- الأنظمة واللوائح: rcrc.gov.sa/en/types/regulations.
- أسئلة أنظمة البناء: rcrc.gov.sa/faqs-categories/أنظمة-البناء.
- **كود وادي حنيفة العمراني**: hanifaurbancode.rcrc.gov.sa — ضوابط الشكل العمراني والواجهات داخل نطاق الوادي.

**قيمة للنظام:** طبقة اشتراطات إضافية فوق اشتراطات الأمانة في النطاقات التي تديرها الهيئة — يجب فحص تداخل النطاق الجغرافي للمشروع.

## 6. الدفاع المدني ومنصة سلامة — Civil Defense & Salamah (998.gov.sa)

- البوابة الرسمية: 998.gov.sa (الخدمات الإلكترونية: 998.gov.sa/ar/Page/Services/1).
- **بوابة سلامة**: salamah.998.gov.sa — إصدار/تجديد تراخيص السلامة إلكترونيًا للمنشآت ذات السجلات التجارية (كود النشاط، المساحة، العنوان → متطلبات سلامة).
- مرتبطة بأحكام SBC 801 للحماية من الحريق.

**قيمة للنظام:** بند «متطلبات الدفاع المدني» في قائمة الجاهزية؛ مستقبلًا: تحقق آلي من متطلبات السلامة حسب كود النشاط.

## كيف تتحول هذه المصادر إلى "معرفة" داخل النظام؟

1. **الفهرسة** — كل مصدر مسجل في `data/regulatory_resource_catalog.json` بحقول الحوكمة الكاملة (source_reference, priority P0/P1/P2, status, binding, confidence_level, last_reviewed_date).
2. **توليد المرشحات** — `GET /v1/rule-candidates/from-resources` ينشئ مرشح قاعدة لكل مصدر. مصادر المسودة/الاستطلاع تُعلَّم «غير قابلة للتصدير» تلقائيًا.
3. **المراجعة المهنية** — مهندس مرخص (SCE) يوثق رقم البند الدقيق من الوثيقة الرسمية + تاريخ المراجعة + مستوى الثقة عبر `POST /v1/rule-candidates/review/validate`.
4. **التصدير كمسودة** — `POST /v1/rule-candidates/review/export-draft-rules` ينتج قواعد **غير مفعّلة وغير رسمية دائمًا**؛ التفعيل قرار تشغيلي منفصل.
5. **المراجعة الدورية** — تحديث `last_reviewed_date` لكل مصدر كل 90 يومًا كحد أقصى (الأكواد تصدر طبعات جديدة — طبعة SBC 201 لعام 2024 مثال).

## ما الذي لا يفعله النظام عمدًا

- لا يسحب نصوص الأكواد آليًا ولا يستخرج قيمًا رقمية منها دون مراجعة مهنية.
- لا يعامل أي مسودة أو استطلاع كمصدر ملزم.
- لا يقدم قيمًا نظامية في المساعد الذكي — يوجّه المستخدم إلى المصدر الرسمي المناسب فقط.
